=====================================================
   PetVida API - Instruções para Testar as APIs
=====================================================

Base URL: http://localhost:5000

Ferramenta sugerida: Postman, Insomnia ou curl

IMPORTANTE: Para as requisições POST, configure o header:
  Content-Type: application/json


=====================================================
1. CADASTRO DE CLIENTE
=====================================================
Método: POST
URL: http://localhost:5000/cadastro-cliente

JSON:
{
    "nome": "João Silva",
    "telefone": "11999999999",
    "email": "joao@email.com"
}

Resposta esperada (201):
{
    "mensagem": "Cliente cadastrado com sucesso",
    "id_cliente": 1
}


=====================================================
2. CADASTRO DE PET
=====================================================
Método: POST
URL: http://localhost:5000/cadastro-pet

OBS: O id_cliente deve existir na tabela clientes.

JSON:
{
    "nome": "Rex",
    "tipo": "Cachorro",
    "idade": 3,
    "id_cliente": 1
}

Resposta esperada (201):
{
    "mensagem": "Pet cadastrado com sucesso",
    "id_pet": 1
}


=====================================================
3. CADASTRO DE FORNECEDOR
=====================================================
Método: POST
URL: http://localhost:5000/cadastro-fornecedor

JSON (com campo produtos):
{
    "nome": "PetShop Distribuidora",
    "telefone": "1133334444",
    "email": "contato@petshop.com",
    "produtos": "Ração, Brinquedos, Medicamentos"
}

JSON (sem campo produtos - é opcional):
{
    "nome": "Veterinária Central",
    "telefone": "1155556666",
    "email": "vet@central.com"
}

Resposta esperada (201):
{
    "mensagem": "Fornecedor cadastrado com sucesso",
    "id_fornecedor": 1
}


=====================================================
4. CADASTRO DE PRODUTO
=====================================================
Método: POST
URL: http://localhost:5000/cadastro-produto

OBS: O id_fornecedor deve existir na tabela fornecedores.

JSON:
{
    "nome": "Ração Premium 15kg",
    "descricao": "Ração para cães adultos de porte grande",
    "preco": 189.90,
    "estoque": 50,
    "id_fornecedor": 1
}

Resposta esperada (201):
{
    "mensagem": "Produto cadastrado com sucesso",
    "id_produto": 1
}


=====================================================
5. CADASTRO DE SERVIÇO
=====================================================
Método: POST
URL: http://localhost:5000/cadastro-servico

OBS: O id_pet deve existir na tabela pets.
OBS: O campo data deve estar no formato AAAA-MM-DD.

JSON:
{
    "tipo_servico": "Banho e Tosa",
    "data": "2026-04-29",
    "valor": 75.00,
    "id_pet": 1
}

Resposta esperada (201):
{
    "mensagem": "Serviço cadastrado com sucesso",
    "id_servico": 1
}


=====================================================
6. CADASTRO DE VENDA
=====================================================
Método: POST
URL: http://localhost:5000/cadastro-venda

OBS: O id_produto deve existir na tabela produtos.
OBS: O id_cliente deve existir na tabela clientes.
OBS: O campo data deve estar no formato AAAA-MM-DD.

JSON:
{
    "quantidade": 2,
    "data": "2026-04-29",
    "valor": 379.80,
    "id_produto": 1,
    "id_cliente": 1
}

Resposta esperada (201):
{
    "mensagem": "Venda cadastrada com sucesso",
    "id_venda": 1
}


=====================================================
          ROTAS GET - LISTAR DADOS
=====================================================

Para todas as rotas GET, não é necessário enviar
nenhum JSON. Basta acessar a URL com método GET.


7. LISTAR CLIENTES
   Método: GET
   URL: http://localhost:5000/clientes

8. LISTAR PETS
   Método: GET
   URL: http://localhost:5000/pets

9. LISTAR FORNECEDORES
   Método: GET
   URL: http://localhost:5000/fornecedores

10. LISTAR PRODUTOS
    Método: GET
    URL: http://localhost:5000/produtos

11. LISTAR SERVIÇOS
    Método: GET
    URL: http://localhost:5000/servicos

12. LISTAR VENDAS
    Método: GET
    URL: http://localhost:5000/vendas


=====================================================
     ORDEM RECOMENDADA PARA TESTAR
=====================================================

Siga esta ordem para evitar erros de chave estrangeira:

1º - Cadastrar Cliente  (POST /cadastro-cliente)
2º - Cadastrar Pet      (POST /cadastro-pet)        -> precisa do id_cliente
3º - Cadastrar Fornecedor (POST /cadastro-fornecedor)
4º - Cadastrar Produto  (POST /cadastro-produto)    -> precisa do id_fornecedor
5º - Cadastrar Serviço  (POST /cadastro-servico)    -> precisa do id_pet
6º - Cadastrar Venda    (POST /cadastro-venda)      -> precisa do id_produto e id_cliente

Depois, use os GETs para verificar se os dados foram inseridos.


=====================================================
     EXEMPLOS COM CURL (Terminal/CMD)
=====================================================

curl -X POST http://localhost:5000/cadastro-cliente -H "Content-Type: application/json" -d "{\"nome\": \"João Silva\", \"telefone\": \"11999999999\", \"email\": \"joao@email.com\"}"

curl -X POST http://localhost:5000/cadastro-pet -H "Content-Type: application/json" -d "{\"nome\": \"Rex\", \"tipo\": \"Cachorro\", \"idade\": 3, \"id_cliente\": 1}"

curl -X POST http://localhost:5000/cadastro-fornecedor -H "Content-Type: application/json" -d "{\"nome\": \"PetShop Distribuidora\", \"telefone\": \"1133334444\", \"email\": \"contato@petshop.com\", \"produtos\": \"Ração, Brinquedos\"}"

curl -X POST http://localhost:5000/cadastro-produto -H "Content-Type: application/json" -d "{\"nome\": \"Ração Premium 15kg\", \"descricao\": \"Ração para cães adultos\", \"preco\": 189.90, \"estoque\": 50, \"id_fornecedor\": 1}"

curl -X POST http://localhost:5000/cadastro-servico -H "Content-Type: application/json" -d "{\"tipo_servico\": \"Banho e Tosa\", \"data\": \"2026-04-29\", \"valor\": 75.00, \"id_pet\": 1}"

curl -X POST http://localhost:5000/cadastro-venda -H "Content-Type: application/json" -d "{\"quantidade\": 2, \"data\": \"2026-04-29\", \"valor\": 379.80, \"id_produto\": 1, \"id_cliente\": 1}"

curl http://localhost:5000/clientes
curl http://localhost:5000/pets
curl http://localhost:5000/fornecedores

curl http://localhost:5000/servicos
curl http://localhost:5000/vendas
